# ADR 0002: 第3幕の幽霊演技をRiveで行う

- 状態: Accepted（2026-10-31）
- 前提: `docs/SPEC.md`、`docs/PLAN.md`、`STORY.md`

## 背景

元の写実的な心霊写真をBlenderの平面に貼り、12枚の画像として書き出す方法では、顔や手の動きが離散的で、自然な関節変形を追加しにくかった。ゴールは世界観の説明ではなく、長押しによる恐怖と「もう離さないと殺される」スリル。

## 採用

Riveで透過画像の頭・腕・胴のアニメーションをネイティブのキーフレームで再生する。Three.jsは教室、幽霊のワールド位置と瞬間移動、露光履歴・死亡判定・写真確定を担当する。Riveの描画をCanvasTextureでThree.jsへ渡すことで、実際の写真にも同じ姿が写る。スクリプトなしのRMLで制作し、CLIでビルドする。

危険域に短い消失・再出現を入れる。Riveに不得手な「3Dの腕をこちらへ突き出す」動作の一部を瞬間移動という幽霊らしい動きに置き換え、遠近と撮影判断を強める。

## 不採用と理由

- Blenderの平面貼り付け連番を継続：修正を加えても動きが切り絵になりやすく、GPU用の長いアトラスが必要。
- 全身の3D幽霊モデル：写実的な造形とリグの制作負担が大きい。現状の写真風美術と統合するまで時間がかかる。
- Riveを全HUDに導入：シャッター操作と写真評価が既存実装で成立しており、必要のない全体改修になる。

## 制約

Riveも画像にない腕の裏側・横顔・手の指関節を作れない。別の原画が必要なら用意する。Rive WASMの追加配布サイズとCanvasTexture更新の負荷はモバイル実機で未評価。動作しなければ静止原画へフォールバックする。撮影判定・死亡時間をRive側の状態機械へ二重実装しない。
