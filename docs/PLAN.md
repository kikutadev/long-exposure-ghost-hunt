### 実行順・受入条件

#### P0｜撮影の面白さを成立させる（他の装飾より優先）

1. **露光の駆け引き**：`IMAGE SHARP / RELEASE` の直接的な正解指示と品質100%ゲージを廃止または初回チュートリアル限定にする。代わりに幽霊の結像、残像の重なり、白飛び・異音・微細な脈動を露光時間に連動させ、これを判断材料にする。音OFFでも見て分かること。
2. **写真と判定の一致**：画角内の幽霊の実際の写り面積、輪郭の鮮明さ、移動による重なり、白飛びを描画側と共通の露光履歴から評価する。同じ霊を短すぎる／ちょうどよい／長すぎる時間で撮った**3枚を横並びで確認**し、ランクが絵の印象と矛盾したら評価式・描画側を調整する。特に空振りが誤って成功しないこと。
3. **機械式シャッター**：押し込み→開放→保持→解放即撮影確定→6枚羽根の閉鎖→残響を、被写体の上で分かる演出にする。金属板の明暗・重なり・開閉の加減速と、ラッチ音＋閉鎖音＋ボディの小さい反動を合わせる。閉鎖モーションはまず100〜140msを試し、端末で見て調整。撮影判定は指を離したフレームで確定、アニメーションを待たせない。
4. **撮影の反復速度**：失敗は理由が写真で読め、1操作で再挑戦できる。現像は心地よく短く、演出のスキップが実際にできるようにする。連打・画面外解放・キャンセル・2本指でも誤動作しない。

**P0合格**：説明を見ずに3種類の露光時間の違いが写真で分かり、プレイヤーが見た目からシャッターを閉じられる。押してからの見た目・音の反応は実機で遅れを感じず、判定と写真が食い違わない。P0が通らなければP1の装飾を増やさない。

#### P1｜一目で「撮りたい」と思う絵を作る

1. **撮影構図**：初期視点の上半分を占める蛍光灯を抑え、怪異の起こる机・黒板・窓へ視線が流れる光と暗部に変更。霊が綺麗に捕捉されたとき写真内で十分な大きさになるよう、距離・FOV・スプライトの表示倍率を調整。無闇な露出上げではなく、主役と背景の明度差を作る。
2. **3体の区別**：徘徊霊はゆっくり衣服の揺れと柔らかい残像、疾走霊は明確な予告→高速通過→短い残像、接近霊は画面内の拡大・音・視野の変化で圧迫感。既存PNGを優先して活用し、追加造形よりも移動・シェーダー・画作りの改善を先に試す。
3. **教室の怪異**：ノート／椅子／蛍光灯／窓の異変を、撮影タイミングにつながる手がかりとして配置。手がかりを聞き逃しても画面で分かる。各幕の照明・音・一箇所の異変で舞台の印象を切り替える（新しい部屋は作らない）。
4. **撮影結果・結末**：幽霊の輪郭を主役とする写真を現像し、エンディングでは3枚の写真を見せてから無人シャッターが1回動く短い出来事を加える。長い説明文や新しいメニューは増やさない。

**P1合格**：縦390×844の「探索／適正露光／撮影結果／3幕目」を並べると、主役と操作の焦点がすぐ分かり、3体の違いが文字を読まなくても理解できる。音とエフェクトを切っても被写体の見た目と動線が成立する。

#### P2｜端末・初見プレイ・配布仕上げ

- 初見の人がガイドを読み切らずに**最初の写真を60秒以内に撮れるか**を観察。3種の速さの違いを自分の言葉で説明できるか、3〜6分で自然に完走できるかを確認。人数が揃わなければ未検証と記録し、数値目標の達成を装わない。

## 実物での合格・不合格

- 10回続けてシャッターを切り、押していないのに露光が続く、解放が遅れる、重複撮影、写真内容のズレが1度も起きない。
- 初見プレイヤーが「長押しで姿が浮かぶ」「離して撮る」を自力で理解できるか。人がいなければ本人が説明なし条件で実機確認し、未検証を明記。
- 早い写真／適切な写真／露光しすぎた写真が同じ幽霊で明確に区別でき、最初の霊は数回以内に成功できる。
- 疾走霊は長い露光よりも短い露光が有利になる。接近霊は待ちすぎると自動閉鎖で失敗する。
- 3〜6分程度で完走でき、失敗時の再挑戦までが短い。写真を表示して次へ進む操作に迷わない。
- 720×1280相当の縦画面でUIが欠けない。実機で30fps以上を目安（端末差は記録）。
- 実機で音あり／音なし、他アプリ復帰、スクロール・長押しメニュー抑止、セーフエリア、非対応向きの表示を検証する。
