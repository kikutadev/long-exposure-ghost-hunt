# LONG EXPOSURE — 完成版の判断とリリース

更新：2026-11-01。現行仕様は [SPEC.md](SPEC.md)、物語は [STORY.md](../STORY.md)。制作過程と旧版の判断はGit履歴を参照。

## ゴール（固定）

スマートフォン縦画面で、**露光を続けたい衝動と、今すぐシャッターを離したい恐怖が衝突する、短く密度の高い3幕ホラー写真ゲーム**を完成・公開する。世界設定や仕組みを100%説明することは目的ではない。3体の顔・手・衣装を実画面で読み取れること、ノート・椅子・足音の怪異と露光が因果的につながること、死亡までの緊張と短い操作テンポを優先。

## 完成版として実装した範囲

- **第1幕**：物理ノートの怪異→俯いた人影が露光で浮かぶ→紙を止め、カメラへ視線を上げる。近めの画角・写真保存・物音同期。
- **第2幕**：窓側の椅子の音→右から左へ0.87秒で走る2姿勢の霊。短時間露光・方向が一致する足音・速度によるブレ。
- **第3幕**：光量が十分に入ると幽霊が撮影者を認識。静止→消失→室内の物体と一緒に近距離出現→カメラに触れた瞬間死亡。顔と手の異なる生成素材、Riveの待機動作を利用。
- **全幕**：露光中の数値は隠し、写真の見え方・音・動きで離すタイミングを判断する。過露光死・接触死、短い現像、失敗の撮り直し、アルバムに実撮影の3枚を蓄積。結果文は写真と矛盾させない。
- **結末**：3枚の実写真→無人の4回目のシャッター音→ `EXPOSURE 004 / OPERATOR: UNKNOWN`。最後の異変が起こるまでREPLAYは出さない。再プレイと死亡リスタートでは完全に状態初期化。
