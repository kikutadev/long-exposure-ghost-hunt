# LONG EXPOSURE — 完成版の判断とリリース

更新：2026-11-02。現行仕様は [SPEC.md](SPEC.md)、物語は [STORY.md](../STORY.md)。制作過程と旧版の判断はGit履歴を参照。

## ゴール（固定）

スマートフォン縦画面で、**露光を続けたい衝動と、今すぐシャッターを離したい恐怖が衝突する、短く密度の高い3幕ホラー写真ゲーム**を完成・公開する。世界設定や仕組みを100%説明することは目的ではない。3体の顔・手・衣装を実画面で読み取れること、ノート・椅子・足音の怪異と露光が因果的につながること、死亡までの緊張と短い操作テンポを優先。

## 2026-11-02 撮影判定と結末の再設計（実装・ブラウザ検証済み）

**目的**：わずかに半透明の人影で成功扱いされないこと、写真が焼けた場合に「失敗→同じ幕でリトライ」の理不尽な結果をなくすこと、腕の差が別の結末につながること。明快な成功・危険・死亡の因果を優先し、失敗するほど待つしかない判定にはしない。

**変更**：
- 成功写真は露光品質の単一閾値だけでなく、実際の露光濃度・鮮明度・被写体の画角占有率・最低可視時間を満たす。成功下限を引き上げ、採用写真の幽霊は人型と顔・姿勢が読める濃度で描画する。
- 過露光の「白飛び」基準を死亡判定にも共有し、危険域を越えた時点で即ゲームオーバー。第1幕は相互観測、第2・3幕は光によるカメラ破損（フィルム焼損）として区別。第2幕の突入死・第3幕の接触死も別の結末として維持。早期警告は音・光の変化で示す。
- 既存4結末を保持し、**フィルム焼損死**と**3枚すべて高画質で記録した別の完走エンド**を追加して6件。通常完走では既存のEXPOSURE 004を残し、高品質完走では同じ記録の異常な印画情報をもう1段階だけ示す。未発見伏せ表示・保存・4/4既存達成記録は消さず6件中の既収集として保持する。隠し記録の解放は6件全収集時に移す。
- エンディングの分岐は撮影品質の**全3枚の結果**で決める。成功した後の無意味な連打・プレイ時間・死亡回数は条件にしない。写真の写り・スコア評価・最後の結果は同じ値を使用する。

**確認済み**：通常完走は品質約74/76/97で従来のEXPOSURE 004、鮮明完走は約99/92/98でUNEXPOSED NEGATIVEに分岐。幕1の過露光死、幕2の過露光死・衝突死、幕3の接触死を実画面で確認。幕3の認識判定は撮影成功と同じ可読条件へ統一し、適正露光約0.75秒でのクリアも維持。写真が薄い場合は再撮影、危険露光は死亡。6件の一覧・旧4件の記録継承と再視聴・6件目自動再生を360×640/390×844のChrome画面で確認。実機の触り心地と恐怖の評価は未確認。

## 隠し記録（2026-11-01初版／2026-11-02に収集条件を6件へ変更）

**目的**：全結末の収集報酬として、1987年の実験がいまだに不気味な形で続いていることを示す**一つの証拠**を見せる。誤って追加した「EXPOSURE 005 / SUBJECT: YOU」やプレイヤー自身の撮影確定を撤去し、既存の「EXPOSURE 004 / OPERATOR: UNKNOWN」の謎を保つ。

**演出**：既存の三体のフィルム像を短く再生→4枚目は見えないまま黒く閉じる→回収された1987年の記録原票が現れる。日付は1987-10-30、教室3-2は23:41に封鎖、カメラの最終シャッター作動は23:48。記録用紙に作動時の撮影者は記録されていない。この**封鎖された後に誰かがシャッターを切ったという時系列**だけを新事実として見せ、誰が切ったか、何が写ったか、三体の正体は示さない。記録の正確さそのものも作品内の一資料として扱い、プレイヤーへ断定ナレーションを与えない。

**実装条件**：素材の新規大量生成はせず、既存の三体の姿・フィルム枠・紙・短い機械音を使用。6/6到達で自動再生（旧4/4収集者は再視聴可）、再訪時は収集画面の「VIEW FINAL RECORD」から任意再生。通常クリア最後でも死亡最後でも元画面へ復帰。文字よりもコマの転換、音の切断、日付・時刻の不一致が見える画面構成を優先する。

**確認**：5枚目や撮影者確定をすべて撤去。390×844・360×640の実画面で記録台帳の封鎖時刻とシャッター作動時刻を目視。4/4の再視聴、死亡を最後にした自動解放、通常クリアを最後にした自動解放、閉じる・REPLAY/RESTARTを確認。32件のテストと本番ビルド、配布ZIP成功。実機評価は未実施。

## エンディング収集（2026-11-01／実装・ブラウザ検証済み）

目的：通常クリア1件と幕別死亡3件、**既存の4種類の結末を見たか**が分かること。隠し分岐やゲーム本編の難易度変更は行わない。タイトル画面から `ENDINGS 00 / 04` を開き、未発見は番号と未発見状態だけ、発見済みはその結末名を表示。死亡の演出が完了して死亡画面が現れた時、クリアは4枚目の異常記録が現れた時に初めて解放する。

記録は同一ブラウザ・同一サイトのlocalStorageへ保存し、RESTART/REPLAYでは初期化しない。ストレージ利用不可でもゲームは続けられ、同一セッション内の達成は保持する。タイトル・死亡・クリア画面から収集状況を閲覧でき、収集画面を閉じると元の画面へ戻る。

確認結果：ローカルの収集・重複・破損ストレージを軽量テスト。ブラウザ390×844で未発見4件、死亡3種の到達後に01→02→03、クリア異常記録後04/04を目視。REPLAYと再読み込みでも04/04が保持され、UIの戻り先と全3幕完走を確認。実機・別デバイス同期は未実施・非対象。

## 第2幕：逃走経路への巻き込まれ（2026-11-01・実装／検証済み）

第2幕では逃走者がこちらを見返さないため、「相互観測で見つかって死ぬ」という第1・3幕用の説明を当てはめない。現行の「白飛び→死亡」の判定は**写真の失敗**と**人物の死亡**を混同する。シャッターを長く開けた場合、扉へ走り去った幽霊が撮影者のいるレンズ側に方向を変えて現れ、進路上の撮影者と衝突した時だけ死亡させる。白飛び・ブレは通常の失敗として再撮影可能。既存の正面向き走行画像と教室内のカメラ転倒を再利用し、命中映像がなければリリースしない。第1幕の過露光死と第3幕の直接接触死は変更しない。

**実画面確認**：390×844の等速ブラウザで右→左の逃走後、扉側から進路を変えてレンズへ接近、実体化した幽霊の正面突入、カメラ転倒、`IT RAN THROUGH.` を連続画像で目視。約2.04秒で離すと生存して `TOO BLURRY`、開け続けると約2.38秒で `RUN_THROUGH` 死亡、RESTARTで初期化。短時間露光成功、3幕→END→REPLAYも確認。テスト30件・ビルド成功、QA Chrome残留0。実機・初見ユーザーの怖さの評価は依然未確認。

## 完成版として実装した範囲

- **第1幕**：物理ノートの怪異→俯いた人影が露光で浮かぶ→紙を止め、カメラへ視線を上げる。近めの画角・写真保存・物音同期。
- **第2幕**：窓側の椅子の音→右から左へ0.87秒で走る2姿勢の霊。短時間露光・方向が一致する足音・速度によるブレ。
- **第3幕**：光量が十分に入ると幽霊が撮影者を認識。静止→消失→室内の物体と一緒に近距離出現→カメラに触れた瞬間死亡。顔と手の異なる生成素材、Riveの待機動作を利用。
- **全幕**：露光中の数値は隠し、写真の見え方・音・動きで離すタイミングを判断する。過露光死・接触死、短い現像、失敗の撮り直し、アルバムに実撮影の3枚を蓄積。結果文は写真と矛盾させない。
- **結末**：3枚の実写真→無人の4回目のシャッター音→ `EXPOSURE 004 / OPERATOR: UNKNOWN`。最後の異変が起こるまでREPLAYは出さない。再プレイと死亡リスタートでは完全に状態初期化。
