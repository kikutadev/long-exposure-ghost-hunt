# Blender制作メモ（LONG EXPOSURE）

**用途**：スマホ縦画面向けThree.jsゴーストハント。幽霊の行動を示す手掛かりを3D化する。

**制作方法**：ホストで起動中のBlender 4.5のシーンをBlender MCP（ポート9877）で直接操作。object_create、object_transform、マテリアル、コレクション、保存・書き出しなどのBlenderオペレーションで段階制作する。外部から一括生成したMeshやプリレンダ画像の代用ではない。

**Production Brief**
- 種別：小道具（hero clue）、ゲーム用、暗い廃校のスタイライズドホラー。
- 対象：古い学習ノート（ページが浮く）、ひび割れた壁掛け時計。
- 予算：両小道具合わせて3000 triangles以下（最終2,108 triangles）、テクスチャ不要、GLBのPBR材質中心。
- 寸法：ノート幅約0.9m、時計直径約0.7m。Three.js世界座標の配置先はノート (-1.40, 1.35, -3.3) 付近、時計 (3.8, 2.65, -8.2)。
- Blender中の位置はGLTF座標変換に合わせ (x, -z, y) を使用。
- 作業ファイル：art/classroom-dress.blend、ランタイム用：public/assets/classroom-dress.glb。
- 作業範囲：造形・マテリアル・シルエット・モデル書き出し。背景・幽霊3枚のPNGと撮影判定は改変しない。
- 受け入れ：Blenderのビューポート・レンダリングで輪郭が読め、GLBを読み込んだ実画面でも既存教室に馴染むこと。検証前に完成とは扱わない。

**検証結果**：Blenderの実操作で44メッシュを作成して保存。レンダリングを確認して表紙の回転を修正、時計部品へDecimateを適用して5,152→2,108三角形に調整。ゲーム実画面では最初のノートが机に隠れる問題があったためBlender上で配置修正。Chrome縦画面で3幕クリア・リプレイ・長押しキャンセルを確認済み。実機タッチ検証は未実施。
